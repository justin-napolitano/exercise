# Exercise

This repository documents personal exercise goals and routines focused on cardio, calisthenics, and balance. It serves as a personal log and plan for maintaining physical activity after relocating to a less walkable environment.

## Features

- Outline of daily exercise goals
- Sections detailing cardio, calisthenics, and balance exercises
- Personal reflections on challenges and adaptations

## Tech Stack

- Markdown for documentation
- Static content, no programming language or framework involved

## Getting Started

This repository contains a single Markdown file (`index.md`). To view the content:

1. Clone the repository:

   ```bash
   git clone https://github.com/justin-napolitano/exercise.git
   cd exercise
   ```

2. Open `index.md` in any Markdown viewer or text editor.

## Project Structure

```
exercise/
└── index.md    # Main document outlining exercise goals and routines
```
